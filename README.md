# Portfolio - CH V V KRISHNA KUMAR

A modern, responsive portfolio website built with React, Vite, TypeScript, and TanStack Router.

## 🚀 Features

- ⚡ **Vite** - Lightning-fast dev server and build
- 🎯 **TanStack Router** - Type-safe file-based routing
- 🎨 **Tailwind CSS v4** - Modern utility-first styling
- 📱 **Fully Responsive** - Optimized for all devices
- 🌙 **Dark Theme** - Beautiful dark color scheme
- 💬 **Contact Form** - WhatsApp & Email integration
- 🔧 **JSON-Driven** - Easy content updates

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite 6
- TanStack Router
- Tailwind CSS v4
- Framer Motion
- shadcn/ui + Radix UI
- Lucide Icons

## 📦 Installation

```bash
npm install
```

## 🚀 Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## 🏗️ Build

```bash
npm run build
```

## 📝 Customization

Edit `src/data/portfolio.json` to update:
- Personal information
- Skills and experience
- Projects
- Contact details
